# LUMI Studio — 官方安装包下载

本仓库仅用于发布 **LUMI Studio** 便携版安装包（Windows / macOS 免安装绿色版，内置运行环境，无需安装 Python 或 Conda）。

## 下载地址

请前往右侧 **Releases** 页面下载最新版本：
- **[v0.2.0 发布页](https://github.com/zhoujujn795/lumi-studio-releases/releases/tag/v0.2.0)**

| 平台 | 文件名 | 启动方式 |
| --- | --- | --- |
| Windows x64 | `LUMI_Studio_Win.zip` | 解压后进入 `LUMI_Studio/` 双击 `LUMI_Studio.exe` |
| macOS (Apple Silicon) | `LUMI_Studio_Mac.zip` | 解压后打开 `LUMI Studio.app` |

## Windows 首次启动提示
- **务必先解压整个 zip 压缩包**再运行，不要在压缩包预览窗口内直接双击 `.exe`。
- 首次启动若 Windows Defender SmartScreen 弹出安全提示，点击 **“更多信息” → “仍要运行”** 即可。
- 压缩包内附带完整图文说明书 `操作手册.md`（配图位于 `docs/images/`）。
